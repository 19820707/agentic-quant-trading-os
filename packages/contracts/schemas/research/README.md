# Research Contracts

Prediction research contracts define non-executable payloads for research dossiers,
probability estimates, hypotheses, analyst reports, debate transcripts, signal
candidates, advisory risk review inputs and local-first agent/tool governance.

These contracts must not contain credentials, private endpoint data, broker or
exchange secrets, wallet keys, executable orders, `ApprovedOrder` payloads or
live trading authority.

Agent/tool governance contracts may describe disabled skills, dependency
declarations, tool permission policy, risk classification, audit records and
loop guards. They must not activate agent runtime, network access, credentials,
shell authority, file-write authority or execution.
