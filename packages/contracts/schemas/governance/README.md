# Governance Schemas

Placeholder for governance, approvals and promotion gate contracts.

Future schemas must preserve approval state, evidence references, human sign-off and rollback metadata.

`ControlLoopManifest` maps critical control-loop stages to platform service
boundaries. It is a control-plane contract only and does not enable Apollo
runtime, Cyber RT, C++ modules, sensor stacks, network access, credentials,
trading execution or production use.
