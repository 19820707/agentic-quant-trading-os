# Schemas

Placeholder JSON Schema domains for future contract-first development.

No schema in this scaffold authorizes live trading or broker execution.

The `research` domain contains non-executable prediction research and multi-agent analysis contracts. Research contracts may produce evidence, estimates, hypotheses, signal candidates and advisory risk-review inputs, but they cannot approve risk or execution.

The `features` domain contains point-in-time dataset lineage and leakage review
contracts. Feature contracts may document dataset readiness for research review,
but they cannot approve model training, production use, risk or execution.
