# Control Plane Dashboard

Static operator-facing control-plane dashboard scaffold.

Current status:

- static HTML/CSS only;
- static contract registry manifest only;
- no API calls;
- no external network access;
- no credentials;
- no authentication yet;
- no broker or exchange access;
- no trading actions;
- no execution controls;
- no runtime data feed.

Open `index.html` directly in a browser for the current local-only preview.

The static contract registry view is generated by hand for this scaffold stage and backed by `contract-registry.json`. It does not read schemas dynamically, call a backend or require a build step.

Future React/Vite/TypeScript implementation requires a separate approval PR before adding frontend dependencies or build tooling.
