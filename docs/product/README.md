# Product Documentation

The product layer — *what* this platform is and *for whom* — alongside the existing
architecture, operations, security and onboarding docs. It exists so any session
(human or agent) can orient on product intent without re-deriving it.

> Bound by the root [`AGENTS.md`](../../AGENTS.md). This layer is descriptive; it
> grants no authority. The Risk Gateway still decides, the audit still proves, and
> going live is human-only.

`docs/architecture/` (incl. `schema_registry.md`), `docs/integrations/`,
